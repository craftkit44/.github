# Support

Projet personnel, sans support commercial ni SLA.

- **Bug** : ouvrir une issue *Rapport de bug*.
- **Idée / évolution** : ouvrir une issue *Demande de fonctionnalité*.
- **Faille de sécurité** : voir [`SECURITY.md`](SECURITY.md) — canal privé, pas d'issue publique.

Les réponses se font au fil de l'eau, sans garantie de délai.
